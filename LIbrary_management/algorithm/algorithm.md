## Algorithm 

Start the program.
Define a node containing Book ID, Book Name, and prev and next pointers.
Initialize the head pointer to NULL.
Display a menu with options to insert, search, display forward, display backward, delete, and exit.
If the user selects Insert, create a new node and connect it to the list while maintaining circular links.
If the user selects Search, enter the Book ID and traverse the list to find the book.
If the user selects Forward Display, display books using the next pointer.
If the user selects Backward Display, display books using the prev pointer.
If the user selects Delete, find the Book ID, remove the corresponding node, and update the pointers.
If the user selects Exit, terminate the program.
Repeat the menu until the user selects Exit.
Stop the program.
