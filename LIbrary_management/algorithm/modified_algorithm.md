## Modified algorithm

Algorithm     

Start the program.

Create a node containing Book ID, Book Name, Author Name, and prev and next pointers.

Initialize the head pointer to NULL.

Display the menu for insertion, searching, forward display, backward display, deletion, and exit.

For insertion, create a new node and update the previous and next pointers.

Maintain the circular connection between the first and last nodes.

For searching, traverse the list until the required Book ID is found or the head is reached again.

For forward display, move through the list using the next pointer.

For backward display, move through the list using the prev pointer.

For deletion, remove the required node and reconnect its previous and next nodes.

Repeat the menu until the user selects Exit.

Stop.
